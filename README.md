# AI Engineer's Handbook

A rich, structured learning path for AI engineering, covering mathematical foundations, machine learning, deep learning, LLMs, retrieval systems, and agentic AI.

## What this project includes

- A full AI curriculum from fundamentals to production-oriented systems
- Interactive course-style modules for each major topic area
- Layout and navigation for learning tracks across the AI stack
- Clean educational content designed for browsing and study

## Tracks covered

- Mathematical foundations
- Classical machine learning
- Deep learning
- Generative AI and LLMs
- AI systems and RAG engineering
- Agentic AI and orchestration

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

This repository is designed as a content-first curriculum app. The homepage, navigation, and course modules are intended to feel like a guided study experience rather than a static landing page.
